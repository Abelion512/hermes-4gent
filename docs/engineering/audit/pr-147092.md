# Audit: PR #147092 — fix(plugins): tell WHY a resolver failed, never downgrade a pin

**Author:** otxboc | **State:** OPEN | **Risk Tier:** T3 | **Auditor:** Hermes Agent

## Summary
Fixes a critical plugin-downgrade bug: `hermes plugins update` could re-pin to an OLDER catalog version than what is installed (e.g., after a `--ref` install on an off-pin commit). Also improves uv resolver error messages and adds AST-based detection for memory provider wrappers that re-export.
